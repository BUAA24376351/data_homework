# 作业：无向图的邻接矩阵和邻接表

**题目：** 给定以下6个顶点的无向图，分别写出其邻接矩阵和邻接表表示。

**顶点：** A, B, C, D, E, F

**图的结构：**
- 六边形环：A—B—C—D—E—F—A
- 对角线：A—C，B—E

---

## 一、邻接矩阵

按顶点顺序 A, B, C, D, E, F：

```
    A  B  C  D  E  F
A [ 0, 1, 1, 0, 0, 1 ]
B [ 1, 0, 1, 0, 1, 0 ]
C [ 1, 1, 0, 1, 0, 0 ]
D [ 0, 0, 1, 0, 1, 0 ]
E [ 0, 1, 0, 1, 0, 1 ]
F [ 1, 0, 0, 0, 1, 0 ]
```

（矩阵为对称矩阵，因为是无向图）

## 二、邻接表

```
A → (B,1) → (C,1) → (F,1)
B → (A,1) → (C,1) → (E,1)
C → (A,1) → (B,1) → (D,1)
D → (C,1) → (E,1)
E → (B,1) → (D,1) → (F,1)
F → (A,1) → (E,1)
```
